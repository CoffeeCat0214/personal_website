# Cutealism Research Pack for Codex
**Prepared:** July 27, 2026  
**Use case:** A cat-forward personal portfolio / creative lab built with Codex  
**Recommended direction:** **Editorial Cutealism** — fashion-editorial restraint with pixel-cat interruptions, tactile neobrutalist structure, and a small number of memorable interactions.

---

## 0. Executive verdict

Cutealism is best understood as a **productive collision**, not a preset theme:

- **Brutalist structure:** visible grids, hard borders, flat fills, blunt typography, offset shadows, exposed hierarchy.
- **Kawaii affect:** friendly characters, soft silhouettes, tiny expressions, candy color, playful language, gentle motion.
- **The tension is the identity:** a soft mascot trapped inside a severe rectangle; a polished serif headline interrupted by a pixel paw; a terminal label that outputs something emotionally warm.

The danger is not “too cute.” The real danger is **generic cute**: pastel SaaS cards, random sparkles, excessive pills, stock kawaii icons, and no structural idea underneath.

For this portfolio, the strongest version is:

> **A high-fashion editorial system that behaves like a cat got into the design studio after midnight.**

The site should look composed at first glance. The mischief reveals itself through hover, motion, marginal annotations, stickers, and the cats’ behavior.

---

## 1. Terminology caveat

“Cute-alism” is an emerging 2026 label rather than a mature, universally agreed design canon. Only a small number of sources use the exact term. Most useful references sit in adjacent categories:

- neobrutalism
- kawaii UI
- playful editorial design
- sticker-bomb illustration
- mascot systems
- retro operating-system interfaces
- gamified web interactions
- expressive maximalism

Codex should therefore **extract individual mechanisms** from each source rather than trying to clone any one reference.

#### 1. Agence Wagner — Cute-alism Design Reference
**URL:** https://agencewagner.com/en/webdesigns/Cute_alism/guide/

**Why it matters:** The clearest implementation-oriented definition found. It describes the aesthetic as a collision between kawaii warmth and brutalist structural honesty.

**Extract:**

- monospace labels

## 5. Recommended design direction: Editorial Cutealism

### Thesis

The site is not a “cute cat portfolio.”

It is the digital residence of a software engineer and creative builder whose cats have acquired editorial authority.

The base layer should feel:
- composed
- intelligent
- sharp
- spacious
- slightly expensive

The cat layer should feel:
- observant
- intrusive
- dryly funny
- tactile
- alive

### Ratio

Use roughly:

```text
70% editorial restraint
20% brutalist structure
10% kawaii disruption
```

The 10% is memorable because it is concentrated.

## 6. Visual system

### Color tokens

```css
:root {
  --ink: #211d1c;
  --paper: #fffaf2;
  --paper-deep: #f3eadc;

  --pink: #ff77b7;
  --butter: #ffd95a;
  --lilac: #b9a4ff;
  --mint: #9ee7c6;
  --sky: #8fd8ff;
  --tomato: #ff6f61;

  --text-primary: var(--ink);
  --text-muted: #655e5a;
  --border: var(--ink);

  --border-thin: 2px;
  --border-strong: 3px;
  --shadow-sm: 3px 3px 0 var(--ink);
  --shadow-md: 6px 6px 0 var(--ink);
}
```

### Color rules

- Body copy stays dark on paper/cream.
- Bright fills are mostly for cards, badges, buttons, and section interruptions.
- Do not place paragraph text on pink, lilac, or yellow without contrast verification.
- One section may use an inverted dark background, but not half the site.
- No default gradients. A gradient must earn its existence through a specific concept.

---

### Typography

**Recommended pairing:**
- Editorial display: `Instrument Serif`
- Structural labels: `Space Mono`
- Body/UI: `Inter`, `Geist`, or the repository’s existing legible sans

**Alternative softer pairing:**
- Display: `Bricolage Grotesque`
- Labels: `IBM Plex Mono`
- Body: `Inter`

**Rules:**
- Serif headlines carry glamour and authorship.
- Mono labels carry the engineering/terminal layer.
- Body text must remain neutral and readable.
- Do not use more than three font families.
- Do not use a novelty font for paragraphs.
- Pixel fonts should appear only in short cat annotations, badges, or easter eggs.

---

### Shape language

Use a deliberate contrast:

| Brutalist form | Cute counter-form |
|---|---|
| square card | rounded cat body |
| thick rectangle | circular eye/paw |
| hard shadow | soft expression |
| mono label | handwritten/pixel annotation |
| rigid grid | sticker crossing the boundary |

### Border language

- Main cards: 3px
- Small chips/controls: 2px
- Illustration outline: visually compatible with 2–3px at intended size
- Avoid mixing hairline borders with heavy borders unless the hairline is inside editorial content

### Shadow language

```css
box-shadow: 4px 4px 0 var(--ink);
```

Hover/press:

```css
transform: translate(2px, 2px);
box-shadow: 2px 2px 0 var(--ink);
```

Pressed:

```css
transform: translate(4px, 4px);
box-shadow: 0 0 0 var(--ink);
```

No blur. The shadow is physical displacement, not atmosphere.

## 7. Component recipes

### Hero

**Structure:**
- oversized editorial statement
- one short mono status label
- one primary CTA
- one secondary text link
- one cat asset participating in the grid

**Interaction idea:** The cat’s eyes follow the pointer within a limited range. On touch devices, the cat blinks or changes pose after a tap.

**Do not:** Build a full-screen game before users can understand who you are.

---

### Project card

```text
[INDEX] 01
Project name
One-sentence outcome
Technology / medium labels
Cat-authored marginal note
```

Interaction:
- card shifts 2–4px
- image crops change slightly
- cat paw may reveal one hidden annotation
- no dramatic 3D tilt on every card

---

### Navigation

- Keep conventional link names.
- Use a rigid bar or boxed tabs.
- Add one cat-specific status item, such as `CAT LAB: ONLINE`.
- Current page must be indicated by more than color alone.
- Mobile navigation should be boring in the best way: obvious, fast, keyboard-safe.

---

### Sticker system

Create three categories:

1. **Identity stickers:** original cat faces, paws, coffee cup.
2. **Structural stickers:** arrows, labels, numbered tabs, tape.
3. **Reaction stickers:** tiny blink, “approved,” “needs more coffee,” “built after midnight.”

Constraints:
- maximum three decorative stickers in the hero
- maximum one sticker crossing a text container
- rotate between -5° and +5°
- never obscure body text or controls
- stickers are `aria-hidden` unless they communicate information

---

### Cat roles

#### Brûlée
- composed
- selective
- quality-control energy
- appears near polished work, approvals, featured projects
- motion: slow blink, tiny head turn, deliberate paw

#### Misu
- curious
- slightly chaotic
- appears near experiments, labs, hidden interactions
- motion: peek, retreat, tail flick, sudden appearance

The cats should not explain the same thing. Distinct behavior creates a real system rather than decorative repetition.

## 8. Motion system

### Principles

1. **Responsive:** motion acknowledges input.
2. **Brief:** most reactions complete in 120–300ms.
3. **Physical:** translate, compress, rotate, collide, peek.
4. **Character-specific:** Brûlée moves slowly; Misu moves quickly.
5. **Optional:** all nonessential movement respects reduced-motion preferences.

### Motion tokens

```css
:root {
  --duration-fast: 120ms;
  --duration-base: 200ms;
  --duration-slow: 360ms;
  --ease-snap: cubic-bezier(.2, .8, .2, 1);
  --ease-bounce-soft: cubic-bezier(.34, 1.56, .64, 1);
}
```

### Performance rules

Animate primarily:
- `transform`
- `opacity`

Avoid animating:
- `width`
- `height`
- `top`
- `left`
- large blur/filter effects
- many box-shadows at once

### Reduced motion

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    scroll-behavior: auto !important;
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

For stateful Rive or canvas motion, implement an explicit reduced-motion branch rather than relying only on global CSS.

## 9. Accessibility and usability guardrails

Use WCAG 2.2 AA as the shipping baseline.

### Minimum requirements

- Text contrast: 4.5:1 for normal text; 3:1 for qualifying large text.
- Keyboard access for every interaction.
- Visible focus states that are not removed for aesthetic reasons.
- No information communicated by color alone.
- Motion triggered by interaction must be suppressible when nonessential.
- Automatically moving content that persists must support pause/stop/hide where required.
- Decorative cats must not pollute the accessibility tree.
- Informative cat expressions need text equivalents.
- Touch targets should remain comfortably tappable.
- Hover-only surprises need focus and touch equivalents.
- No scroll hijacking.
- No autoplay audio.

**References:**
- https://www.w3.org/TR/WCAG22/
- https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html
- https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html
- https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html
- https://web.dev/articles/animations-guide
- https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion

## 10. Anti-patterns

Reject the implementation when it does any of the following:

- looks like a generic pastel SaaS template
- uses twenty pill-shaped components
- uses blurred shadows
- adds gradients by default
- imports stock cat characters
- mixes pixel art, 3D clay, anime, flat vector, and editorial collage on one screen
- makes every element wiggle
- hides navigation inside an experiment
- uses a loader longer than the real load time
- makes desktop delightful and mobile broken
- treats decorative stickers as content
- places text inside moving objects
- uses Dribbble mockups as proof that a pattern works responsively
- clones copyrighted characters or distinctive living artists’ exact work

## 14. Final recommendation

Build the site as a controlled duality:

- The **grid** says software engineer.
- The **serif** says author.
- The **mono labels** say systems thinker.
- The **cats** say no institution gets to flatten the person who built it.

Cutealism works here because it is not decoration pasted over credibility. It is the visible argument that rigor and delight can occupy the same machine.
